# Variables de Entorno

Este proyecto requiere las siguientes variables de entorno. Copia `.env.template` a `.env` y configura los valores apropiados.

## Variables Requeridas

### Base de Datos
```env
DATABASE_URL="postgresql://usuario:contraseña@host:puerto/nombre_bd?schema=public"
```

### Servidor
```env
PORT=3001
```

### PDF
```env
PDF_OUTPUT_DIR="./output"  # Desarrollo: carpeta local
# PDF_OUTPUT_DIR="/var/www/pdfs"  # Producción: ruta absoluta del servidor
```
**Nota:** Si no se especifica, usa la carpeta `output` dentro del proyecto por defecto.

### Correo Electrónico

#### Configuración SMTP
```env
MAIL_HOST="mail.gavacyc.com"          # Servidor SMTP
MAIL_PORT=465                         # Puerto SMTP (465 para SSL, 587 para TLS)
MAIL_FROM="az.sistema@gavacyc.com"   # Correo remitente del sistema
MAIL_PASSWORD="tu_contraseña_aquí"   # Contraseña del correo del sistema
```

#### Destinatarios de Logística
```env
MAIL_LOGISTICS_TO="logistica@gavacyc.com"                    # Correo principal de logística
MAIL_LOGISTICS_CC="copia1@gavacyc.com,copia2@gavacyc.com"   # Correos en copia (separados por coma)
```

#### URLs de la Aplicación
```env
APP_URL="https://sir.gavacyc.com"                          # URL base de la aplicación
RESET_PASSWORD_URL="https://sir.gavacyc.com/reset-password" # URL para resetear contraseña
```

## Seguridad

⚠️ **IMPORTANTE**: 
- **NUNCA** hagas commit del archivo `.env` al repositorio
- El archivo `.env` debe estar listado en `.gitignore`
- Solo comparte el archivo `.env.template` con valores de ejemplo
- Para producción, configura las variables de entorno directamente en el servidor o usa un servicio de gestión de secretos

## Configuración por Entorno

### Desarrollo
Crea un archivo `.env` en la raíz del proyecto con tus valores locales.

### Producción
Configura las variables de entorno en tu servidor o plataforma de hosting:
- Para servidores Linux: usa archivos de configuración del sistema o servicios como systemd
- Para servicios en la nube: usa las herramientas de gestión de variables de entorno de tu proveedor (AWS Secrets Manager, Azure Key Vault, etc.)
- Para contenedores Docker: usa archivos `.env` o pasa las variables con `-e` o `--env-file`

## Ejemplo de Uso en Docker

```bash
docker run -d \
  -e DATABASE_URL="postgresql://..." \
  -e MAIL_PASSWORD="contraseña_segura" \
  tu-imagen:latest
```

O con archivo `.env`:
```bash
docker run -d --env-file .env tu-imagen:latest
```
